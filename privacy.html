Политика конфиденциальности

«rclone» — личное приложение одного владельца (ilyazioc@gmail.com), которое нужно только для доступа владельца к собственному Google Диску из программы rclone.

Приложение не собирает, не хранит на сторонних серверах, не продаёт и не передаёт третьим лицам никакие данные пользователей. Токены доступа хранятся только в локальном конфигурационном файле rclone на компьютерах владельца.

Privacy Policy

“rclone” is a personal app used solely by its owner (ilyazioc@gmail.com) to access the owner's own Google Drive via rclone. It does not collect, store remotely, sell or share any user data. Access tokens are kept only in the local rclone configuration file on the owner's machines.
